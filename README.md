# Ninja77030's DS Library

## A beginner's library for basic data structures

This library was built for ensuring that beginners in C++ can use basic data structures without going through the difficulty of making it themselves, but by using this library which is simply defined for users to even read, analyze and offer suggestions to this project

### How to install

After cloning the repository, head to the directory using a terminal and build it using
```bash
cmake -B build
```
Then, you can install using <br>
```bash
sudo cmake --install build
```
